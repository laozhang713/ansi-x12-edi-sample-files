2. ANSI X12 Technical Deep Dive: Preventing $250–$750 Retail Chargebacks

2.1 Walmart Cross-Dock SDQ Destination Quantity Decompression

In cross-dock procurement (Walmart, Home Depot, Costco), the retailer ships freight to a single Regional Distribution Center (N1*ST) while embedding store-by-store allocation pairs inside the SDQ (Destination Quantity) segment: 

PO1*1*100*EA*12.50*WE*UP*012345678905*IN*554433221*VN*SKU-TOWEL-BLU-L*UK*10012345678902~
PID*F*08***ORGANIC COTTON BATH TOWEL ROYAL BLUE~
PO4*10*1*EA~
SDQ*EA*92*0101*25*0102*35*0103*40~

Here, Store #0101 receives 25 EA, Store #0102 receives 35 EA, and Store #0103 receives 40 EA—summing to exactly 100 EA (PO102). You can flatten multi-store SDQ segments into individual warehouse picking rows using the EDI to CSV / Excel Converter or export directly to fulfillment via the EDI 850 to ShipStation CSV Integration.

2.2 Implied Two-Decimal (N2) Formatting in TDS and SAC05

While line-item unit prices in PO104 / IT104 use explicit decimals (type R, e.g., 12.50), both the TDS (Total Monetary Value Summary) and SAC05 (Service, Promotion, Allowance Amount) segments use strict N2 implied two-decimal integers: 

TDS*230500*233000*225840*4660~
SAC*A*D240***2500**********PROMOTIONAL ALLOWANCE~

Sending an explicit decimal point (e.g., TDS*2305.00~ or SAC*A*D240***25.00~) causes immediate AP rejection via an EDI 824 Application Advice (TED*848). Use the EDI 850 to 810 Invoice Generator to compute exact N2 cent integers automatically.

2.3 Target 5-Tier S-O-T-P-I Hierarchy & SSCC-18 Modulo-10 Barcodes

Big-box distribution centers require a 5-level HL (Hierarchical Level) tree inside every EDI 856 Advance Ship Notice: Shipment (S) → Order (O) → Tare/Pallet (T) → Pack/Carton (P) → Item (I). At the Tare and Pack levels, the MAN*GM segment carries the 20-digit GS1-128 container ID (AI 00 + 18-digit SSCC-18). Verify check digits with the SSCC-18 Check Digit Calculator and generate physical 4x6 thermal labels with the GS1-128 Shipping Label Generator.
